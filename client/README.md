# muiogo-client

Thin Python client and `muiogo` CLI for the MUIOGO HTTP API. Mechanical work
only — session handling, case/scenario CRUD, run launch + polling, results
download. No analysis, no judgment: that lives in the skills.

Status: skeleton. Phase-0 deliverable per `../docs/SCOPE.md`.

Develop with `uv sync` in this directory; run the CLI with `uv run muiogo`.
